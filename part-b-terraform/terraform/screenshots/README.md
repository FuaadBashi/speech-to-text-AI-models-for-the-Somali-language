This directory should contain evidence screenshots for your assessment submission.

1. **terraform-apply-success.png**

   - Should show all resources created without errors

2. **load-balancer-working.png**

4. **auto-scaling-instances.png**
   - Huawei Cloud Console screenshot
   - Auto Scaling → Scaling Groups → Instance List
   - Should show 2+ instances, ideally 3-4 during load test

5. **database-created.png**
   - Huawei Cloud Console screenshot
   - RDS → Instances
   - Showing your MySQL database instance details

6. **vpn-connected.png**
   - VPN client screenshot showing successful connection
   - Should include connection status and routes

## How to Take Screenshots

### MacOS
- `Cmd + Shift + 4` - Select area to capture
- `Cmd + Shift + 3` - Capture entire screen

### Windows
- `Win + Shift + S` - Snipping tool
- `PrtScn` - Screenshot to clipboard

### Linux
- `gnome-screenshot -a` - Select area
- `gnome-screenshot` - Full screen

## Tips for Good Screenshots

- Use high resolution (at least 1920x1080)
- Ensure text is readable
- Include timestamps where relevant
- Crop to show relevant information
- Save as PNG for better quality
- Name files exactly as specified above
